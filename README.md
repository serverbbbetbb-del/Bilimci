⚙️ Gurnamak

Ilki Node.js gurnalan bolmaly.

Soňra taslama bukjasynda:

npm install

Serveri işletmek üçin:

npm start

Development režiminde:

npm run dev

Soňra brauzerde:

http://localhost:3000

adresini aç.

🤖 AI

AI backend arkaly birikdirilýär.
